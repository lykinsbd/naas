Un-deprecate the unversioned /healthcheck endpoint. Per ADR 0012, /healthcheck is now treated as a permanent operational endpoint for k8s probes, Docker HEALTHCHECK, and similar infrastructure tooling — it does not emit deprecation headers and will not be removed in v3.0. The versioned /v1/healthcheck remains deprecated alongside other /v1/ routes; /v2/healthcheck is now also registered for clients that want an explicit version. Deprecation banners across README and docs no longer list /healthcheck among the deprecated unversioned aliases (/send_command and /send_config are still deprecated).
