Split sync-release.yml's bump-develop job into a separate workflow (bump-develop.yml) that triggers on the main → develop sync PR merge instead of on the release/X.Y → main merge. The previous behavior branched bump-develop from develop before the sync PR opened, causing its diff to be stale by the time the sync PR merged. With the split, bump-develop runs after develop is in its post-release state. Also documents the 'fix-on-release-branch-first' pattern in development.md, ADR 0011, and the agent prompt to avoid orphan changelog fragments (#503).
